
----------------------------------------------------
INSTRUMENT FILE FORMAT
----------------------------------------------------





(1 byte) Volume

(1 byte) UNUSED

(1 byte) Arppeggio speed/length

For all 8 arp values:
	|
	| (1 byte) Arp value
	|

(1 byte) Modulation type/scale

(1 byte) Envelope scale

For all 2 waves:
	|
	| (1 byte) Noise Volume
	|
	| (1 byte) Wave type
	|
	| (1 byte) Offset + Octave
	|
	| (1 byte) Release
	|
	| (1 byte) Boolean flags
	|
	| For all 8 frequencies:
	|	|
	|	| (1 byte) Frequency value
	|	|
	|
	| For all 32 envelope points:
	|	|
	|	| (1 byte) Amplitude
	|	|
	|
	|
